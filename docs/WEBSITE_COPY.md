# 学社官网展示文案

项目名称：DSH 桌面提示音

一句话介绍：为 Codex 与 GPT Work 桌面工作流添加自动声音反馈，任务完成、等待确认和最终失败各有对应提示。

项目简介：围绕“无需额外操作”的目标，项目实现了原生状态观察、事件分类、重复提示过滤、后台播放及全屏静音保护。提供面向普通用户的一键安装程序，音频随包分发，安装目录随电脑自动适配。日常使用保持原有客户端操作习惯。

展示要点：原生桌面工作流；完成/确认/错误三类声音；共享去重；全屏静音；一键安装与通知设置恢复。

适用平台：Windows 11 x64；支持含 Work / Codex 的已核验客户端版本。普通 Chat 与网页不支持。

建议按钮：“下载 Windows 安装包”“查看源码”“使用与兼容说明”。链接分别使用：

- 下载：https://github.com/Redhood-Heqing/dsh-desktop-sounds/releases
- 源码：https://github.com/Redhood-Heqing/dsh-desktop-sounds
- 使用与兼容说明：https://github.com/Redhood-Heqing/dsh-desktop-sounds#下载与安装

来源署名：提示音采用 dsh-theme-tarkov 项目资源，保留上游 MIT 许可。本项目为社区辅助工具，与 OpenAI 无官方隶属关系。

展示边界：可描述已实现功能及本机验证结果；不要宣传支持所有 GPT 客户端、所有游戏、零性能开销或所有电脑均已验证。图片/录屏如后续添加，请使用专用演示聊天，避免出现账号、私人会话和本机路径。
